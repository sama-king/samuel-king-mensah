# Samuel King-Mensah portfolio

Run `npm run dev`, then open http://127.0.0.1:4500.

Static HTML, CSS and JavaScript, with no build step or production dependencies. Deploy the contents of `site/` or the portfolio ZIP to a static host. `server.mjs` is only the local preview server.

- `index.html`: semantic page content, all five project articles, language/framework proficiency, career and contact information.
- `styles.css`: supplied identity, responsive art direction, gallery and proficiency styling.
- `app.js`: scroll-driven project rail, direct navigation, proficiency fills and project-aware email destinations.
- `projects/*.html`: one page per project (core features, architecture component map, innovation highlights, technology stack). Generated by `node lab/build-projects.mjs` from `lab/projects-data.mjs` (copy) and `lab/projects-arch.mjs` (components and connections); edit the data, not the HTML. Shared `projects/project.css` and `projects/project.js`.
- Opening a project uses cross-document View Transitions (Chrome and Edge 126+, Safari 18.2+): the gallery image morphs into the project hero. Other browsers navigate normally.
- `assets/projects/`: actual project images and app marks. Source provenance README is excluded from deployment.
- `assets/portrait-samuel-v3.webp`: transparent portrait generated from Samuel's three supplied photographs, using the original placeholder only for its folded-arm pose and gentle smile. Its original PNG is kept in `assets/source/`. The visible caption identifies it as based on those photos.
- `BRIEF.md`: creative choices, user direction, content provenance and rating assumptions.
- `VERIFICATION.md`: actual checks and testing limits.

The five projects sit in a one-screen gallery that scrolls sideways (swipe, trackpad, shift+wheel, drag or arrows); vertical scrolling passes over it. Named project links and arrows jump directly to a project. Continue to skills exits the gallery. Reduced motion, short landscape screens and JavaScript-disabled browsing expose all five projects vertically. Notes and contact remain available with reduced motion; no-JavaScript visitors retain the full summaries and direct contact links.

FrontDesk and Loveworld Security use real app logos as temporary identity graphics, pending screenshots the user will provide. LumosCast uses its existing console design. employed uses a capture with fictional demo data. RabahFoods uses an actual public website capture.

The portrait was generated with the built-in image tool from the three supplied photos; the changed Kie key was not needed. Generation can closely follow facial references but does not preserve every pixel of an original photograph. The supplied JPEGs are not bundled in the deployment package.

Ratings: Kotlin, Python, PHP and VBA are grouped as Advanced at the user’s request. .NET, React and Node.js remain Familiar and appear with JavaScript/TypeScript, Java and SQL in the main list; those three languages remain Proficient. Named levels are qualitative, not percentages.

The shared Scroll Craft engine is unchanged. Fonts are local and licensed. No third-party scripts, private app data, credentials, personal CV source or referee details are deployed. Email links open the visitor's mail application; no message is sent by the page.

`lab/v1-source/` and earlier QA folders preserve the superseded design. Current checks are `lab/revision-check.mjs`, `lab/revision-functional.mjs`, and the revision Scroll Craft screenshot sets.
