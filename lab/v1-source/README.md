# Samuel King-Mensah portfolio

Run `npm run dev`, then open http://127.0.0.1:4500.

This is a static website with no build step and no production dependencies. `server.mjs` is a local preview server only. Deploy the contents of `site/` after the final packaging step to any static host.

- `index.html`: page structure, career copy, contact information, and profile links.
- `styles.css`: layout, responsive composition, and theme.
- `app.js`: project content, system illustrations, accessible selection controls, and project-specific email links.
- `assets/portrait-placeholder.webp`: generic AI portrait placeholder. Replace with the user's approved photograph before a personal production launch. Its visible caption and alt text explicitly identify it as temporary.
- `assets/skm-logo.png`: cropped from the supplied logo with original colors and transparency retained.
- `BRIEF.md`: design and content rationale.
- `VERIFICATION.md`: evidence and limits of testing.

The project graphics are explanatory system maps, not application screenshots. Project notes distinguish demonstrated implementation from unverified deployment status. No confidential source code or private application records are bundled.

The source CV is used for professional copy only. Its referees' contact details are not included in the site. Contact links open the visitor's email application; there is no form backend or implied message delivery.

The shared Scroll Craft engine is copied unchanged. Page-specific behavior lives in `app.js`. Fonts are local with their license in `assets/fonts/`.
